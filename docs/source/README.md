## Как таблицы попадают в агент

В рантайме таблицы не читаются. Из них один раз собран
`apps/api/src/bot/library/seed/default-library.json` — стандартная
библиотека, которую владелец загружает в аккаунт кнопкой на вкладке
«Агент» (`POST /telegram/accounts/:id/bot/library/import`). Дальше тексты
правятся только в вебе; повторный импорт с `mode: replace` возвращает их к
исходным, не трогая включённость.

Пересобрать сид после правки таблиц:

```bash
cd apps/api && node scripts/build-library-seed.mjs <папка с распакованными funnel/ и diagnostics/>
```

xlsx распаковывается как zip (`Expand-Archive` в PowerShell), скрипт читает
XML без зависимостей. Соответствие ячеек видам библиотеки описано в самом
скрипте; `npm test` проверяет собранный сид (`default-library.spec.ts`).

Что заменено плейсхолдерами: биография старого образа → `{{bio}}`, ссылки
старого аккаунта → `{{links}}`. Оба берутся из образа аккаунта при
отправке. Тексты написаны от лица практика-мужчины («Я вернулся»); для
образа с женским полом диагностики нужно переписать.

Не из таблиц: вопросы знакомства `agent.*` (вопрос о сфере, уточнения для
отношений и семьи — вид `ask_request` с категорией; повторная просьба о
дате рождения — вид `ask_birth_data`) дописаны в самом скрипте. В уже настроенный аккаунт они попадают импортом с `mode: keep`:
он добавляет новые элементы и не трогает существующие.

Тоже не из таблиц: фразы `real.*` — то, что живой человек стабильно писал
в реальной переписке аккаунта (разбор 01.10.2026,
`docs/real-dialogs-report.md`): раздел «о себе и о работе», возражения
после диагностики, недостающие возражения после вариантов, частые
напоминания, а также то, что было в убранных примерах диалогов и чего в
библиотеке не было. Они тоже дописаны в скрипте. В уже настроенные
аккаунты их добавляет `node scripts/apply-real-dialogs.mjs` (повторяемо;
`--revert` убирает добавленное). Вопрос о сфере `agent.ask_sphere` с 01.10
— открытый, как у человека, а «работаю онлайн» — с репликой человека
(«энергия не имеет границ»); скрипт меняет их в аккаунте, только если
текст там ещё прежний.

Не импортируются: видео-варианты («варианты с видео окошками», «видео в
храме»), «вибрации», бесплатная практика, касания после цен (после цен
агент выключен), лист «наставничество», листы «ТЕСТ».
